Send to Reader

iPhone: share sheet

  1. Open Shortcuts, tap +, name it Send to Reader.
  2. Tap the ⓘ and turn on Show in Share Sheet.
  3. Add the action Get Contents of URL with this URL:
  4. In that action tap Show More: Method POST, Request Body JSON, add a Text field named url and set it to Shortcut Input.
  5. Add Get Dictionary Value: key message.
  6. Add Show Notification with the Dictionary Value.

Then in Safari, X or any app: Share → Send to Reader.
